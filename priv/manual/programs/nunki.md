# The hall announcer

Nunki reads the pairings aloud in the hall as soon as they are published,
and counts down to the start of the round ("Round 3 starts in five
minutes"). It is a small program on a computer with speakers, and it speaks
English or Dutch, whichever the tournament speaks. It uses the computer's
own voices, so it keeps announcing with every page closed, and it has a hall
screen for a projector.

**When you need it.** In a hall where the pairings are read out, or where a
countdown to the start of the round saves the arbiter a walk to the
microphone. What is announced and when is decided in OpenPairings; Nunki is
where it is said out loud. With rooms, an announcer reads only its own room's
boards.

**Desktop or hosted.** It works with the desktop OpenPairings on the same PC
as well as with the hosted server: the desktop build has the announcer built
in. Install Nunki next to OpenPairings (Ascella does both) and paste the
join link into it, the same as with a server.

**Where it fits.** In OpenPairings: the tournament's Settings, *Hall
announcer*, *Add an announcer*; the link it shows is good once, for fifteen
minutes. Paste it into Nunki on the hall PC, or scan its QR code with
[Manubrium](/help/manubrium-app) on your phone, which passes the link on
(copy or share) to the PC. Rooms are set in
[Creating a tournament and its settings](03-tournament-setup.md#rooms-page). Its sister
in the hall is [Polis](/help/other/polis), which prints the same rounds.
