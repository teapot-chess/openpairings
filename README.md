# OpenPairings downloads

Release builds of OpenPairings, the chess tournament manager. The source code is not public; this repository holds only the downloads.

**[Latest release](https://github.com/teapot-chess/openpairings-releases/releases/latest)**

| System | File |
|---|---|
| Windows, installer (recommended) | `OpenPairings-<version>-win-Setup.msi` |
| Windows, installs for you only, no questions | `OpenPairings-<version>-win-Setup.exe` |
| Windows, no install | `openpairings_portable_windows_x86_64.zip` |
| Linux | `openpairings_portable_linux_x86_64.zip` |

`SHA256SUMS` lists every file's checksum. An installed copy finds its updates here by itself.

The hosted version needs no download: [pairings.cloud](https://pairings.cloud).
